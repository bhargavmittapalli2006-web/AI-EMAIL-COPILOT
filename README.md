# AI Email Copilot

An intelligent email management system featuring automated email analysis across four core AI engines:

1. **Priority Engine** - Determines email importance and urgency.
2. **Security/Phishing Engine** - Detects phishing attempts, calculates risk scores, and provides safety explanations.
3. **Understanding Engine** - Summarizes email content, identifies intent, and extracts key entities.
4. **Action Engine** - Extracts actionable tasks, detects deadlines, and suggests replies.

> **Current Focus:** Phase 1 - `phishing-engine` foundation.

---

## Directory Overview

- `phishing-engine/`: Microservice for phishing detection and email risk analysis.
- `data/`: Dataset storage for raw and processed training data.
- `docs/`: System documentation, API specs, and architecture diagrams.
